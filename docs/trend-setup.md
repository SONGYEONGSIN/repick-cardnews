# 트렌드에서 주제 가져오기 — 키 발급

주제를 직접 타이핑하는 대신 **요즘 뜨는 것 중에서 고르려면** 키 두 개가 필요합니다.
인스타 설정보다 훨씬 간단합니다 — 심사도, 계정 전환도, 터널도 없습니다.

## 무엇을 하는가

1. **유튜브 인기 급상승(한국)** 에서 후보를 가져온다
2. **Claude** 가 30~40대 맘의 생활 정보로 바꿀 만한 것만 추리고 **순위를 매긴다**
3. *(선택)* **네이버 데이터랩**이 있으면 30~40대 여성 검색 비중으로 **순위를 다시 매긴다**
4. 상위 10개 안팎을 보여 준다 — 고르면 그대로 카드 만들기로 넘어간다

**필요한 키는 유튜브 하나**입니다(1번). 네이버는 있으면 더 정확해지는 선택 사항입니다.

---

## 1. 유튜브 API 키

영상 데이터를 읽기만 하므로 **API 키 하나면 됩니다.** 로그인 연동(OAuth)은 필요 없습니다.

1. https://console.cloud.google.com 에서 프로젝트를 만듭니다(이미 있으면 그걸 써도 됩니다)
2. **API 및 서비스 → 라이브러리** 에서 **YouTube Data API v3** 를 찾아 **사용 설정**
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**
4. 만들어진 키를 복사합니다

> **할당량**: 하루 10,000유닛이 무료이고 이 앱의 호출은 **1회에 1유닛**입니다.
> 하루에 수천 번 눌러도 남습니다.

**키 제한을 걸어 두면 더 안전합니다** — 사용자 인증 정보에서 그 키를 눌러
**API 제한**을 `YouTube Data API v3` 하나로 좁히세요.

---

## 2. NAVER API HUB — **선택. 없어도 동작합니다**

> ### 먼저 읽으세요 — 네이버는 창구가 두 개입니다
>
> 검색어트렌드 데이터를 주는 곳이 둘인데 **서로 호환되지 않습니다.**
>
> | | developers.naver.com | **NAVER API HUB** (이 앱이 쓰는 곳) |
> |---|---|---|
> | 어디 | 네이버 개발자센터 | **네이버 클라우드 플랫폼** (console.ncloud.com) |
> | 호스트 | `openapi.naver.com` | `naverapihub.apigw.ntruss.com` |
> | 인증 헤더 | `X-Naver-Client-Id` | `X-NCP-APIGW-API-KEY-ID` |
>
> **한쪽 키로 다른 쪽을 부르면 `errorCode 024`(인증에 실패했습니다)가 납니다.** 키가 틀린
> 것처럼 보여서 한참 헤매게 됩니다 — 2026-08-02 에 실제로 겪었습니다. 이 앱은 **API HUB**
> 쪽으로 부릅니다.
>
> 없어도 주제 추천은 동작합니다. 유튜브 키만으로 후보를 가져오고 Claude 가 추려서
> 순위까지 매깁니다. 검색어트렌드가 붙으면 **30~40대 여성 검색 비중**으로 순위를 다시
> 매기는 단계가 추가될 뿐입니다. 화면은 지금 순위가 **어느 근거인지** 표시합니다.

**2-1.** https://console.ncloud.com 에 로그인 → **NAVER API HUB** 로 들어갑니다.
(콘솔 검색창에 `API HUB` 를 치면 빠릅니다.)

**2-2. Application 등록** — 이름은 아무거나. `repick-cardnews` 정도면 됩니다.

**2-3. 사용할 API** — **`Data Lab` 범주의 `검색어트렌드`** 를 고릅니다.

헷갈리기 쉬운 것:
- 같은 `Data Lab` 의 **`쇼핑인사이트`** 는 **다른 API** — 쇼핑 카테고리 통계라 우리가 쓸 게 아닙니다
- `NAVER 검색` 범주(`성인 검색어 판별`·`지역`·`뉴스`)도 별개입니다

**이미 등록했는지 확인**하려면 **Application Management** 의 `API 관리` 표를 보세요.
`Data Lab / 검색어트렌드` 줄이 있으면 등록된 것입니다.

**2-4. 키 받기 — 여기가 핵심**

`API 관리` 표 위의 **`인증 정보`** 버튼을 누르면 **Client ID** 와 **Client Secret** 이
나옵니다. **이 팝업의 값이어야 합니다** — 콘솔 계정의 액세스 키(마이페이지 쪽)나 개발자센터
값을 넣으면 `024` 로 거절당합니다.

> 콜백 URL·웹 서비스 URL 은 안 물어봅니다 — 서버에서 직접 부르는 방식이라 필요 없습니다.
>
> 검색어트렌드는 **하루 50,000회**까지 쓸 수 있고, 이 앱은 주제 한 번 가져올 때
> 후보 5개당 1회씩만 부릅니다.

## 3. `.env.local` 에 넣기

저장소 루트의 `.env.local` 에 세 줄을 더합니다(이미 인스타 설정이 들어 있는 그 파일입니다):

```
YOUTUBE_API_KEY=
NAVER_CLIENT_ID=
NAVER_CLIENT_SECRET=
```

넣은 뒤 **dev 서버를 다시 시작**하세요.

> **네이버 키가 틀려도 주제 추천은 그대로 동작합니다.** 데이터랩 순위 매기기만 건너뛰고
> 화면이 "네이버에 연결하지 못해 Claude 판단 순서로 정렬했다"고 알려 줍니다.
>
> `errorCode: 024` (`인증에 실패했습니다`)가 나면 **거의 항상 창구를 잘못 고른 것**입니다
> — 데이터랩 권한 문제가 아닙니다. **개발자센터(developers.naver.com) 키를 넣지 않았는지**
> 먼저 확인하세요. 이 앱은 **NAVER API HUB** 의 `인증 정보` 팝업에 나오는 값만 받습니다
> (2번 항목의 비교표 참고).

## 4. 확인

첫 화면(`/`, 주제)에서 트렌드 목록을 불러 봅니다.
안 되면 **무엇이 빠졌는지 한국어로** 알려 줍니다.

## 알아 둘 것

**데이터랩이 주는 값은 실제 검색 횟수가 아니라 상대값입니다.**
후보끼리 "어느 쪽이 더 검색되나" 를 비교하는 데만 쓸 수 있고,
"이 키워드는 한 달에 N번 검색됨" 같은 말은 만들 수 없습니다.

**유튜브 인기 급상승은 전 연령·전 주제입니다.**
연예·정치·특정 사건이 많이 섞여 있어서, 2단계(Claude)가 생활 정보가 될 만한 것만
걸러 냅니다. 그래도 어울리지 않는 게 올라오면 그냥 안 고르시면 됩니다.

**연령 구간은 확인했습니다** (2026-08-02).
데이터랩의 `ages` 값은 `1`=0\~12, `2`=13\~18, `3`=19\~24, `4`=25\~29, `5`=30\~34,
`6`=35\~39, `7`=40\~44, `8`=45\~49, `9`=50\~54, `10`=55\~59, `11`=60세 이상입니다.
이 앱은 `5·6·7·8`, 즉 **30\~49세**로 조회합니다.
