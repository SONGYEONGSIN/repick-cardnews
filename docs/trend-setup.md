# 트렌드에서 주제 가져오기 — 키 발급

주제를 직접 타이핑하는 대신 **요즘 뜨는 것 중에서 고르려면** 키 두 개가 필요합니다.
인스타 설정보다 훨씬 간단합니다 — 심사도, 계정 전환도, 터널도 없습니다.

## 무엇을 하는가

1. **유튜브 인기 급상승(한국)** 에서 후보를 가져온다
2. **Claude** 가 30~40대 맘의 생활 정보로 바꿀 만한 것만 추리고 **순위를 매긴다**
3. *(선택)* **네이버 데이터랩**이 있으면 30~40대 여성 검색 비중으로 **순위를 다시 매긴다**
4. 상위 10개 안팎을 보여 준다 — 고르면 그대로 카드 만들기로 넘어간다

**필요한 키는 유튜브 하나**입니다(1번). 네이버는 있으면 더 정확해지는 선택 사항입니다.

---

## 1. 유튜브 API 키

영상 데이터를 읽기만 하므로 **API 키 하나면 됩니다.** 로그인 연동(OAuth)은 필요 없습니다.

1. https://console.cloud.google.com 에서 프로젝트를 만듭니다(이미 있으면 그걸 써도 됩니다)
2. **API 및 서비스 → 라이브러리** 에서 **YouTube Data API v3** 를 찾아 **사용 설정**
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**
4. 만들어진 키를 복사합니다

> **할당량**: 하루 10,000유닛이 무료이고 이 앱의 호출은 **1회에 1유닛**입니다.
> 하루에 수천 번 눌러도 남습니다.

**키 제한을 걸어 두면 더 안전합니다** — 사용자 인증 정보에서 그 키를 눌러
**API 제한**을 `YouTube Data API v3` 하나로 좁히세요.

---

## 2. 네이버 개발자센터 앱 — **선택. 없어도 동작합니다**

> **2026-08-02 확인**: 애플리케이션 등록의 **사용 API 목록에 `데이터랩` 이 안 보인다.**
> 네이버가 별도 **`API 제휴 신청`**(개발자센터 왼쪽 메뉴)으로 옮겼을 가능성이 있다.
>
> **없어도 주제 추천은 동작한다.** 유튜브 키만으로 후보를 가져오고 Claude 가 추려서
> 순위까지 매긴다. 데이터랩이 붙으면 **30~40대 여성 검색 비중**으로 순위를 다시 매기는
> 단계가 추가될 뿐이다. 화면은 지금 순위가 **어느 근거인지** 표시한다.
>
> 나중에 제휴 신청이 통과하면 아래 값만 채우면 자동으로 켜진다 — 코드를 고칠 필요 없다.

검색어 트렌드(데이터랩)를 쓰기 위한 것입니다. 등록 자체에는 심사·요금이 없습니다.

**2-1.** https://developers.naver.com 에 **평소 쓰는 네이버 계정**으로 로그인
(별도 개발자 가입 절차 없음)

**2-2.** 상단 **Application → 애플리케이션 등록**

**2-3. 애플리케이션 이름** — 아무거나. `repick-cardnews` 정도.
사용자에게 안 보입니다(로그인 연동 API 를 쓸 때만 동의 화면에 뜨는데 우리는 안 씁니다).

**2-4. 사용 API — 여기가 핵심**

목록에서 **`데이터랩 (검색어 트렌드)`** 를 고릅니다.

헷갈리기 쉬운 것:
- **`데이터랩 (쇼핑인사이트)`** 는 **다른 API** — 쇼핑 카테고리 통계라 우리가 쓸 게 아니다
- **`검색`** 도 별개 — 뉴스·블로그 검색용. 지금은 불필요

나중에 같은 앱에 API 를 추가할 수 있으니 지금은 하나만 고르면 된다.

**2-5. 비로그인 오픈 API 서비스 환경**

`WEB 설정` 을 고르고 **웹 서비스 URL** 에:

```
http://localhost:3500
```

**실제 운영 사이트가 아니어도 된다.** 서버에서 직접 호출하는 방식이라 이 URL 이 검사에
쓰이지 않는다. 형식만 맞으면 된다.

**2-6.** 등록하면 **Client ID** 와 **Client Secret** 이 나온다.
다시 볼 때는 **Application → 내 애플리케이션 → (앱 이름) → 개요**.

> 콜백 URL 은 안 물어본다 — 그건 네이버 로그인 연동용이고 우리는 안 쓴다.
>
> 화면의 정확한 항목 이름·배치는 네이버가 바꿨을 수 있다. **"데이터랩 (검색어 트렌드)" 를
> 고르고 Client ID·Secret 을 받는 것**이 핵심이니 중간 화면이 조금 달라도 괜찮다.

## 3. `.env.local` 에 넣기

저장소 루트의 `.env.local` 에 세 줄을 더합니다(이미 인스타 설정이 들어 있는 그 파일입니다):

```
YOUTUBE_API_KEY=
NAVER_CLIENT_ID=
NAVER_CLIENT_SECRET=
```

넣은 뒤 **dev 서버를 다시 시작**하세요.

> **네이버 키가 틀려도 주제 추천은 그대로 동작합니다.** 데이터랩 순위 매기기만 건너뛰고
> 화면이 "네이버에 연결하지 못해 Claude 판단 순서로 정렬했다"고 알려 줍니다.
>
> 네이버가 `errorCode: 024` (`인증에 실패했습니다`)를 주면 **키 값 자체가 잘못된 것**입니다
> — 데이터랩 권한 문제가 아닙니다(권한 문제면 다른 코드가 옵니다). 이때 흔한 원인은 개발자센터
> 앱의 값이 아닌 다른 걸 붙여넣은 경우입니다. **Client Secret 은 보통 10자 안팎**이라,
> 눈에 띄게 길면 다른 값일 가능성이 높습니다. **Application → 내 애플리케이션 → (앱) → 개요**
> 에서 다시 확인하세요(시크릿은 `보기` 를 눌러야 보입니다).

## 4. 확인

`/cardnews` 첫 화면(주제)에서 트렌드 목록을 불러 봅니다.
안 되면 **무엇이 빠졌는지 한국어로** 알려 줍니다.

## 알아 둘 것

**데이터랩이 주는 값은 실제 검색 횟수가 아니라 상대값입니다.**
후보끼리 "어느 쪽이 더 검색되나" 를 비교하는 데만 쓸 수 있고,
"이 키워드는 한 달에 N번 검색됨" 같은 말은 만들 수 없습니다.

**유튜브 인기 급상승은 전 연령·전 주제입니다.**
연예·정치·특정 사건이 많이 섞여 있어서, 2단계(Claude)가 생활 정보가 될 만한 것만
걸러 냅니다. 그래도 어울리지 않는 게 올라오면 그냥 안 고르시면 됩니다.

**연령 구간은 확인했습니다** (2026-08-02).
데이터랩의 `ages` 값은 `1`=0\~12, `2`=13\~18, `3`=19\~24, `4`=25\~29, `5`=30\~34,
`6`=35\~39, `7`=40\~44, `8`=45\~49, `9`=50\~54, `10`=55\~59, `11`=60세 이상입니다.
이 앱은 `5·6·7·8`, 즉 **30\~49세**로 조회합니다.
